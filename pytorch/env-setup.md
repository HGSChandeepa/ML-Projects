# Setup Instructions

## Create virtual environment in the root directory
```bash
python -m venv .venv
````

## Activate (each new terminal)

### macOS/Linux:

```bash
source .venv/bin/activate
```

### Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

### Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

## Install dependencies

```bash
pip install -r requirements.txt
```
